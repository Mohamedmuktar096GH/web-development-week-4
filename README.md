# SpendWise Dashboard Shell

A responsive financial tracking application dashboard shell framework built with CSS Grid and Flexbox layouts.

## Features Implemented:
* **CSS Grid Page Layout:** Structures the macroscopic layout into discrete header, sidebar, and main-content grid areas.
* **Flexbox Component Design:** Used to horizontally align structural elements within the main header, wrap custom stat cards safely, and handle inner layout stacks.
* **CSS Custom Properties (Variables):** Defined within the `:root` selector for centralized control over global metrics such as brand, accent, surface, backgrounds, and multi-tier typography scales.
* **Typography:** Integrated Google Fonts connections referencing Inter and Plus Jakarta Sans.
